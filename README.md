# BlueMagnet App Console

Interactive unified Streamlit console.

## Clickable / interactive controls
- Sidebar navigation buttons for every dashboard
- Attribution model selector
- Reset dashboard button
- B2B channel and period filters
- Customer journey drill-down selector
- Account intelligence drill-down selector
- Interactive Streamlit charts and tables

## Dashboards
Executive Dashboard, B2B Performance, Attribution, Customer Journeys, Sales Pipeline, Account Intelligence, ROI & Growth.

Currency: ZAR / South African Rand.

Run:
```bash
pip install -r requirements.txt
streamlit run app.py
```
